Bienvenue dans mon home lab Microsoft Intune

Ce repository a pour objectif de documenter ma pratique et mon apprentissage sur Microsoft Intune.

À travers ce projet, je souhaite comprendre à quoi sert Microsoft Intune, à qui il s’adresse et comment l’utiliser dans un environnement professionnel.

Qu'est ce que Microsoft Intune ?

Microsoft Intune est une solution de gestion d'appareils et des applications basée sur le cloud. Il permet aux administrateur informatique de centraliser la gestion des comptes la sécurisation et la configuration d'une organisation

Mon environnement

* Ordinateur principal : MacBook M2
* Virtualisation : Parallels Desktop
* Machine virtuelle : Windows 11 Pro ARM64
* Administration : Microsoft Intune
* Gestion des identités : Microsoft Entra ID
